# 🎬 비즈니스 실무 AI 영상 — 5단계 시나리오 생성 파이프라인 (vc2030-01)

이 스킬은 **실무 기획안(PDF · TXT · 월드빌딩 텍스트 등)**을 유일한 입력값으로 받아, 체계적인 5단계 파이프라인을 거쳐 **최종 5대 마스터 대본(이미지·영상·나레이션·자막·효과음/돌발대사)**을 완벽하게 산출하는 비즈니스 실무 AI 영상 기획 표준 프로토콜입니다.

> **기존 `ai-video-pipeline` 스킬과의 차별점**: 동화·애니메이션 스타일이 아닌 **실제 CEO·기업인·비즈니스 현장** 시나리오에 특화. PDF 기획안 직접 분석 지원, 실사 드라마틱 영상 스타일 적용.

산출된 대본은 **Google Flow, Google Vids, Vrew, CapCut, Wondershare Filmora, Runway Gen-3, Luma Dream Machine, Kling, Midjourney** 등에서 원스톱으로 즉시 사용할 수 있습니다.

---

## 🎯 핵심 5단계 파이프라인 워크플로우

```
[사용자 입력: 기획안 텍스트 / PDF 내용 / 월드빌딩 설정]
        │
        ▼
[1단계] 주인공 및 주요 등장인물 캐릭터(1~N) 생성 (비주얼 DNA & 외형 프롬프트)
        │
        ▼
[2단계] 캐릭터 시트(다각도 턴어라운드 + 핵심 감정 표정 4~6종) 생성
        │
        ▼
[3단계] 기승전결 N장면 줄거리(시놉시스) 구성 (시간 배분 & 감정선)
        │
        ▼
[4단계] 각 장면별 시나리오 연출 확장 (시공간, 구도, 행동/제스처, 템포)
        │
        ▼
[5단계] 각 장면별 용도별 5대 마스터 대본 일괄 생성 (가장 중요!)
        ├── 🖼️ Track 1. 이미지 생성용 대본 (영문 프롬프트, 실사 / 3D 선택)
        ├── 🎥 Track 2. 동영상 생성용 대본 (카메라 무빙 & 모션)
        ├── 🎙️ Track 3. 나레이션용 대본 (TTS 호흡 쉼표 포함 한국어)
        ├── 📝 Track 4. 자막용 대본 (가독성 1~2줄)
        └── 🔊 Track 5. 사운드 디자인 (돌발 대사, SFX, BGM 무드)
```

---

## 📥 입력 규격 (Input Specification)

사용자가 제공하는 **기획안 텍스트 하나**만으로 전 과정이 자동 실행됩니다.

### 최소 입력 형식

```text
[주제/성미]: (예: 이안나 대표 해외수출 10억 달성 기념 홍보 영상)
[주인공]: (이름, 나이대, 국적, 직업/역할)
[상대 인물]: (이름, 나이대, 국적, 직업/역할) — 있을 경우
[장면 수]: (예: 8장면, 총 약 2~3분)
[비주얼 스타일]: (예: 실사 드라마틱 / 3D 애니메이션 / 웹툰 풍)
[추가 설정]: (배경지, 핵심 사건, 감정 키워드 등 자유 기술)
```

### 권장 입력 (고품질 출력 보장)

- PDF 기획안 전문 붙여넣기
- 기업 보도자료 / 인물 소개서
- 월드빌딩 설정 문서

## 📋 단계별 상세 실행 가이드라인

### [1단계] 주인공 및 주요 등장인물 캐릭터(1~N) 생성

비즈니스 인물의 **전문성과 개성**이 시각적으로 전달되도록 캐릭터 설계합니다.

- **캐릭터 프로필**: 이름, 나이대, 국적, 직함, 성격·리더십 스타일, 시그니처 복장(정장·케주얼 등), 헤어스타일, 컬러 팔레트
- **비즈니스 비주얼 DNA 키워드**: 실제 CEO·기업인답게 보이도록 설계된 앵커 키워드 3~5개 (영문)
- **Master Character Prompt (영문)**: Google Flow / Midjourney / Imagen 3 / Flux 공용 고품질 마스터 프롬프트
  - 구성: `[렌더 스타일: 실사 / 3D] + [인물 설명 & 나이대] + [복장 & 액세서리] + [배경 환경] + [조명 & 분위기] + [카메라 렌즈]`

### [2단계] 캐릭터 시트(Character Sheet) 생성

비즈니스 인물의 다양한 상황별 표정과 자세를 확보합니다.

- **턴어라운드 뷰(Turnaround Sheet)**: 순백색 배경 위 전신(정면·3/4·측면·후면)
- **비즈니스 핵심 표정 4~6종**: 자신감 있는 프레젠테이션 표정, 진지한 협상 표정, 환한 악수 / 성공 미소, 경청하는 집중 표정, 감동/감사 표정, 결단력 있는 서명 장면

### [3단계] 기승전결 N장면 줄거리(시놉시스) 구성

비즈니스 스토리의 **감동 서사 구조**를 설계합니다.

- **기(起)** : 인물 소개 & 도전 배경 제시 (20%)
- **승(承)** : 핵심 사건 전개 & 협업/협상 과정 (30%)
- **전(轉)** : 결정적 순간 / 예상치 못한 돌파구 (30%)
- **결(結)** : 성공·감동 마무리 & 미래 비전 (20%)
- 각 장면당 **약 15~25초**, 총 6~8장면 기준

### [4단계] 각 장면별 시나리오 연출 확장 (Cinematic Direction)

각 장면에 대해 4대 연출 요소를 구체화합니다:

1. **시간 및 배경 환경 (Location & Lighting)**: 비즈니스 공간(회의실·라운지·공항·전시장 등), 조명 톤, 배경 소품
2. **카메라 샷 구도 (Cinematography)**: Wide shot, Medium shot, Close-up, Over-the-shoulder, Tracking shot 등
3. **캐릭터 행동 및 표정 연출 (Acting & Gesture)**: 악수, 서명, 프레젠테이션, 시선 교환, 리액션
4. **분위기 및 템포 (Mood & Pacing)**: 긴장감, 여유, 기대감, 감동, 성취감 등

### [5단계] 각 장면별 용도별 5대 마스터 대본 생성

모든 장면(Scene 1~N)에 대해 다음 **규격화된 서식**으로 통일하여 출력합니다:

```markdown
[ N장면 ] 🎬 Scene N : [장면 제목]

• 🖼️ [이미지용 대본] (Google Flow / Midjourney / Imagen 3 호환)
  [Visual DNA 앵커] + [동작/상황] + [배경/조명] + [카메라 앵글] + [스타일] --ar 16:9

• 🎥 [동영상용 대본] (Runway Gen-3 / Luma / Kling / Veo 2 호환)
  [카메라 무브먼트: Dolly/Pan/Tracking] + [피사체 모션] + [환경 모션] + cinematic lighting

• 🎙️ [나레이션용 대본] (Google Vids / Vrew TTS 호환)
  "호흡 쉼표와 감정 지시문이 포함된 자연스러운 한국어 스토리텔링 대본 (2~3문장)"

• 📝 [자막용 대본] (CapCut / Vrew 화면 하단 자막)
  화면 가독성에 맞춘 1~2줄 핵심 문구 (20자 내외)

• 🔊 [사운드 디자인]
  - 💬 돌발 대사: 캐릭터 현장 대사/감탄사
  - 🎵 효과음(SFX): 구체적 폴리 사운드 키워드 (영문)
  - 🎼 BGM: 장면 무드 및 추천 악기 구성
```

## 🛠️ 편집 툴 연동 안내

1. **Google Flow (flow.google.com)**
   - Track 1 이미지 프롬프트 → 실사/3D 배경 및 장면 이미지 생성
   - Track 2 동영상 프롬프트 → I2V (Image-to-Video) 클립 생성
2. **Google Vids (vids.google.com)**
   - Track 2 클립들을 타임라인에 배치
   - Track 3 나레이션을 `[Script]` 패널에 입력 → 한국어 AI 음성 생성
   - Track 4 자막을 하단 텍스트 박스에 입력
   - Track 5 SFX & BGM 추가 후 오디오 더킹 적용
3. **Vrew / CapCut / Filmora**
   - Track 3 나레이션으로 텍스트→비디오 자동 생성
   - Track 4 자막을 SRT로 변환 (→ `scripts/extract_to_srt.py` 활용)
